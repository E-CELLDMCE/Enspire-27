# ENSPIRE'27 Frontend

A React + Vite responsive frontend inspired by the cinematic business atmosphere of *The Wolf of Wall Street* (2013).

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite.

## Build
```bash
npm run build
```

## Movie stills
The site intentionally does not generate images. Add authentic stills that you have permission to use:
- `public/assets/movie-stills/hero.jpg` — hero background
- `public/assets/movie-stills/closing.jpg` — final CTA background

If those files are absent, the page still renders with dark fallback backgrounds and gold graphics. Use licensed/authorized images before public deployment. Do not hotlink random image URLs.
